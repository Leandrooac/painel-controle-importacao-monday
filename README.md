# Painel de Controle de Processos de Importação — Monday.com

## Contexto

O controle dos processos de importação era feito inteiramente em planilhas de Excel, sem padronização entre os responsáveis e sem visão centralizada de status (canal de parametrização, exigências, pendências documentais). Com o volume de processos crescendo, as planilhas isoladas deixaram de funcionar para o acompanhamento em equipe.

A estruturação foi feita internamente, sem consultoria externa nem plataformas especializadas de Trade Management.

## Abordagem

Participei da construção do painel com uma equipe de 3 pessoas, primeiro como Assistente de Importação e Exportação e depois como Analista de Importação. O trabalho envolveu:

1. Mapeamento das etapas reais do processo de importação, da abertura até a admissão em entreposto aduaneiro.
2. Estruturação dessas etapas como fluxo de status no Monday.com (canal de parametrização, verificação de Licença de Importação, exigências, despacho).
3. Migração progressiva dos controles que existiam só em Excel para o painel, centralizando o acompanhamento da equipe.
4. Ajustes contínuos conforme o processo evoluía, incluindo a transição do modelo de DI para a DUIMP.

## Ferramentas

- Monday.com (quadros, colunas de status e automações nativas)
- Microsoft Excel (controle anterior, usado como referência para o mapeamento)

## Resultado

- Acompanhamento dos processos de importação centralizado para toda a equipe, substituindo planilhas individuais e dispersas.
- Status e pendências visíveis em tempo real, sem atualização manual cruzada entre arquivos.

## Sobre os dados neste repositório

Este repositório não reproduz o painel real nem dados de fornecedores, processos ou produtos. Documenta a lógica de estruturação do fluxo.
